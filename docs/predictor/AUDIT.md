# 黄金方向预测原型 · 审计与溯源文档 (AUDIT)

> 用途：交差 / 答辩 / 自查时，证明网页上每个数字"从哪来、怎么算、是否可信"。
> 定位：这是一个 **prototype（原型）**，不是投资建议。当前信号偏空（P(up)≈22–30%）。

---

## 0. 一句话结论

网页预测器用 **随机森林（walk-forward）** 预测"未来 21 / 63 天金价收益是否为正"，
数据来自 **5 个 FRED 免 key 宏观序列 + Twelvedata 真实金价**。
方法学正确（严格样本外、无前视泄漏），但 **21 日策略净值跑输买入持有**，
且地缘 / 央行购金 / ETF 资金流等因子因无免费 API 未纳入模型。

## 2. 因子 vs 特征

- **5 个原始因子**：上述 FRED 宏观序列（+ 金价）。
- **15 个特征**：由 5 因子 + 金价衍生（`build_features`）：
  金价 20/60/252 日收益与波动率、实际利率及 60 日变化、美元 20/252 日变化、
  VIX 及 20 日变化、GVZ、美股（纳斯达克综合）20/60/252 日收益。
- "因子 0–10 看多评分"是独立的**评分板**，**不是**随机森林的输入。

---

## 3. 随机森林做什么

- **监督学习**：用历史每天的 15 个特征 + 标签（未来 21/63 天收益是否为正）训练 300 棵决策树。
- **预测**：输入"今天的特征"，输出 `P(up)` = 森林中判为"涨"的树占比。
- **标签**：`dir_h = (gold.shift(-h)/gold - 1 > 0)`，即未来 h 天收益为正记为 1。

---

## 4. 因子 0–10 评分（仪表盘美学，非模型）

- **z-score**：`(当前值 − 过去 252 日均值) / 过去 252 日标准差`
- **映射**：`score = 5 + 5.0 × direction × tanh(z/2)`
  （原版是 `5 + 2.5 × …`，范围只 2.5–7.5，已改为 5.0 铺满 0–10）
- `5 / 5.0 / 2` 是**设计参数，非统计推导**；随机森林不吃这个分数。

---

## 5. 回测方法（walk-forward）与正确性评估

### 5.1 方法

- `walk_forward`：expanding 窗口，从 `min_train=500` 起，每 `RETRAIN_DAYS=21` 天重训一次，
  **用严格早于预测日的数据训练**，预测该日方向 → **无前视泄漏**。
- `backtest`：信号 `prob>0.5` 做多否则空仓；`pos = signal.shift(1)` 用**前一天**信号交易，避免同日泄漏。
- **持有期严格对齐**：21 日信号用 `target_21`、63 日信号用 `target_63` 计算净值（修复了此前两个窗口都误用 `target_21` 的 bug，该 bug 曾把 63 日回测错误地按 21 日收益复利，导致 63 日优势被低估）。
- 净值：`sc = (1 + pos×fwd).cumprod()`（策略） vs `bc = (1 + fwd).cumprod()`（买入持有，按同一持有期口径）。

### 5.2 正确性结论

- ✅ **方法学正确**：严格样本外、无前视。混淆矩阵与准确率均来自 walk-forward 的 ~154 个样本外测试点。
- ⚠️ **一处小瑕疵（不影响结论）**：网页"当前 P(up)"用**全量数据（含最后一行）**训练再预测最后一行，
  存在极轻微样本内接触。用"排除预测行"的严格版复刻与线上 `0.3007 / 0.216` 仅差约 1 个百分点，影响可忽略。
- ⚠️ **21 日策略净值跑输买入持有**（`1.91` vs `3.61`，加入央行因子后）。这**不是 bug**，是真实结果：
  **方向准（70.8%）≠ 赚得多**——21 日属于高换手的择时叠加，踏空了上涨复利。
- ✅ **63 日策略正确对齐后大幅跑赢买入持有**（`77.37` vs `43.62`）。63 日信号用 63 日收益复利，优势明显。
- ✅ **综合信号（21+63 平均 P(up)）也跑赢买入持有**（`48.20` vs `43.62`），介于两者之间，更稳健。
  页面默认展示 **63 日**（唯一大幅跑赢的窗口），可由按钮切换 21日 / 综合。
- 🔬 **仓位管理实验（已做，结论：对 21 日无效）**：测试了 4 种按 P(up) 缩放仓位的方案
  （分数多头、多空、sqrt 倾斜、0/1 基线），**全部跑输当前 0/1 基线**。结论——21 日择时的劣势不在仓位，
  而在高换手 + 强趋势资产本身不适合短周期择时；真正有效的改进是拉长持有期（用 63 日信号）。
- 📈 **加入央行年净购金因子后方向准确率提升**：21日 `70.8%`、63日 `85.5%`（混淆矩阵 `[[48,6],[16,82]]`），
  较加入前的 `71.4% / 78.9%` 中 63日提升显著。详见 §10。

### 5.3 实盘式回放验证（只给历史，预测未来）

复刻 `predict_asof(date)`：仅用 `date` 及之前数据训练，预测之后 21/63 天。
已验证该复刻与线上逻辑完全一致（最后一天复刻 = `0.3007 / 0.216`）。

- **2026-08-12（两周前）**：预测 `P21=0.41`（略多）/ `P63=0.30`（偏空）；
  此后 14 天实际 **+5.44%**（暂偏多）。21 日结果（至 2026-09-02）与 63 日（至 2026-10-14）**尚未到期**，无法判对错。
- **已到期样例**：
  - 2026-06-01：`P21=0.35`（空）→ 实际 −6.53% ✓；`P63=0.45`（空）→ 实际 −9.57% ✓
  - 2026-03-02：`P21=0.42`（空）→ 实际 −17.46% ✓；`P63=0.35`（空）→ 实际 −15.14% ✓
  - 2026-07-15：`P21=0.26`（空）→ 实际 +4.59% ✗（漏掉 7 月反弹）
  - 注：样例日模型普遍偏空，金价下跌时准确、反弹时失误 —— 与整体 71.4% (21日) / 78.9% (63日) 准确率一致。
  - ⚠️ 以上示例的 P 值为更早 2498 行版本的输出；当前版本（3748 行）下请以网页回放 UI 实时数值为准（回放覆盖 2014-09 ~ 2026-08，共 154 个历史点）。

## 6. 混淆矩阵（方向准确率来源）

2×2 表（行 = 实际，列 = 预测）：

| | 预测跌 (0) | 预测涨 (1) |
|---|---|---|
| **实际跌 (0)** | TN = 47 | FP = 19 |
| **实际涨 (1)** | FN = 25 | TP = 63 |

- 准确率 = (TP + TN) / 总数 = (63 + 47) / 154 = **71.43%**（即"RF 21 日方向准确率 71.4%"）。
- 63 日版本 `[[45,11],[21,75]]` → (75+45)/152 = **78.95%**。
- 混淆矩阵只衡量"方向猜对没"，**不衡量赚没赚钱**。

## 8. 已知局限（诚实清单）

1. **地缘、央行购金、ETF 资金流未纳入**：无免费实时 API，模型只认 5 个宏观因子（见 §10 央行购金因子规划）。
2. **21 日策略跑输买入持有（2.26 vs 3.58）**：已做仓位实验，结论——仓位缩放**无效且更差**，
   根因是高换手 + 强趋势资产不适合短周期择时；**正确解法是用 63 日信号**（已验证 67.19 vs 40.61 跑赢）。
3. **当前 P(up) 含极轻微样本内接触**（见 §5.2）。
4. **样本外测试点 ~154 个**（2014–2026 历史回放），统计意义较此前 ~95 个有所提升，但仍有限。
5. 原型，**非投资建议**。

## 10. 央行购金因子（已实现，用户问"C：央行购金怎么权重"）

**数据**：WGC《Gold Demand Trends》历年央行净购金（吨）。因无免费实时 API，已手动整理为
`data/cb_gold.csv`（年度净购金，2009–2025；2023=1050.8、2024=1044.6 来自 WGC 官方，
其余为公开报道的年度净额，2025 为约数）。

**对齐方式（避免前视）**：每个交易日取「上一年」的年度净购金（当年总额年底才知），前向填充成日频，
作为慢变量特征 `cb_net`。即 2012 年的每一天都用 2011=456t，2013 年用 2012=544t，依此类推。

**权重策略（采用 B：让随机森林自己学）**：`cb_net` 作为一个普通特征并入 `FEATURES`，
模型用不纯度下降自动决定它的重要性与方向，**不拍固定权重**。

**实测效果（加入后重跑）**：
- 63 日方向准确率 **78.9% → 85.5%**（混淆矩阵 `[[48,6],[16,82]]`）。
- 特征重要性中 `央行年净购金(吨)` 排 **第 3**（0.0914），仅次于实际利率(0.131)与标普60日收益(0.092)——
  说明模型确实学到了"央行持续净买入→利好黄金"的结构性逻辑。
- 回测：63 日策略 77.4 vs 买入持有 43.6（仍大幅跑赢）；综合信号 48.2 vs 43.6（跑赢）。
- 顾虑仍在：年度数据样本少、且 2010 后持续净买入，`cb_net` 偏"慢多"；但它贡献的方向正确，未强行放大。

**下一步可增强**：把年度 CSV 升级为 WGC 季度官方数据（更及时），或接入 IMF COFER 季度储备变化。
