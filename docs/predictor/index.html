📖 这些数字是怎么算出来的？（方法说明，点击展开）

一、上传面板里那几个指标（自动分析你的金价数据）

  • 动量（momentum）：某周期收益率。252日动量 = 最新价 ÷ 252个交易日前的价格 − 1；20日/60日同理。它衡量"这段时间涨了多少"。
  • 最大回撤（max drawdown）：历史上"从某阶段最高点，跌到之后最低点"的最大跌幅。公式 max( (价格 − 截至当日最高点) ÷ 最高点 )。它衡量"最坏情况下你会亏多少"。
  • 年化波动率（annualized vol）：先算每日收益率 (今日价 ÷ 昨日价 − 1)，求其标准差，再 ×√252（一年约 252 个交易日）年化。它衡量"抖不抖"。
  • 状态（regime）—— 为什么叫"反弹"？
    • 多头：252日动量 > 0 且 最新价 ≥ 252日均线 → 长期向上，价格在均线之上。
    • 反弹：252日动量 > 0 但 最新价 < 252日均线 → 长期趋势仍向上，但价格短暂跌破年均线，属于"上涨趋势里的一次回调"，所以是反弹不是反转。
    • 高位震荡：252日动量 ≤ 0 但 最新价 ≥ 252日均线 → 价格还在均线上，但年度趋势已转弱。
    • 空头：252日动量 ≤ 0 且 最新价 < 252日均线 → 全面走弱。

二、模型预测页的数值（来自随机森林）

  • 未来上涨概率 P(up)：随机森林在两个时间窗口（21日 / 63日）上，根据 16 个因子判断"未来是涨还是跌"的概率。概率 > 50% 判为"涨"。
  • 当前因子 0–10 看多评分：把 5 个核心因子先做 z-score（减均值除标准差，把不同量纲拉到同一尺度），再经 tanh 压到 ±1，映射成 0–10。>5 偏多，<5 偏空。
  • 回测：策略净值 vs 买入持有：用"前一天的信号"决定当天仓位（概率>0.5 做多，否则空仓；综合信号取 21日+63日 P(up) 的平均）。把每日收益复利累加得"策略净值"，和"一直持有"对比。
    结论：21日策略跑输买入持有（高换手踏空复利）；63日策略大幅跑赢；综合信号也跑赢。所以页面默认展示 63日。
  • 回放里的"模型预测路径"（第 3 条线）：用回归器预测未来 21/63 日的收益率（连续值），反推成价格点，连到预测日。它是一条"点预测"轨迹，短期会偏离真实价格——这正常，模型本职是判断方向，不是精确画价格。

三、回放里"未来涨跌有多少"怎么看

  • 选定日期后，信息栏会给出：模型预测未来 21/63 日收益率 X%，以及到如今实际收益率 Y%（涨/跌），并标注方向命中 ✅ / 未命中 ❌。
  • "预测收益"来自回归器，"实际收益"是该日后真实金价算出的收益率；两者符号一致即方向命中。

四、上传即预测（用你自己的数据训练）

  • 这是页面最底部独立的模块：把你自己的金价序列（如 Gold.xlsx）选进来点“训练并预测”，浏览器会用这段历史独立训练一个随机森林（从零实现，不含宏观因子）。
  • 它用 9 个技术面特征（5/20/60/252 日收益率、20/60 日波动率、价格相对 MA20/60/252 的偏离）预测未来 21 日 / 63 日的涨跌方向（P 涨）与幅度（收益率 %）。训练按时间顺序 80% 训练、20% 样本外测试，并报告测试集方向准确率。
  • 它与上方“宏观因子模型”是两套独立逻辑：前者只看你数据的技术形态，后者看宏观基本面，结论可能不同。幅度是点估计、误差较大，方向（P 涨）才是较可靠的部分。

数据：FRED 免 key 宏观因子 + 金价历史（Twelvedata）+ 央行年净购金（WGC）。模型：walk-forward 随机森林，严格样本外、无前视。原型，非投资建议。
